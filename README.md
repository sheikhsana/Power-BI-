# 📊 Sales Performance Analysis Dashboard

Project Overview

This project is an interactive Sales Performance Dashboard created using Microsoft Power BI.

The dashboard analyzes sales performance across different cities, product categories, and products. It provides a clear view of key business metrics such as sales, profit, orders, and quantity.

The project was created as a portfolio project to demonstrate practical skills in data analysis, data visualization, and dashboard development using Power BI.

---
Project Objective

The main objective of this project is to analyze sales data and create an interactive dashboard that helps users understand:

- Overall sales performance
- Profit performance
- Order and quantity trends
- City-wise sales performance
- Category-wise sales performance
- Top-performing products
- Monthly sales trends

---

Tools & Technologies

- Microsoft Power BI
- Data Analysis
- Data Visualization
- Interactive Dashboards
- Excel/CSV Dataset

---

Key Performance Indicators

The dashboard includes the following KPIs:

- Total Sales
- Total Profit
- Total Orders
- Total Quantity

---

Dashboard Features

### 1. Monthly Sales Trend
Shows how sales performance changes over time and helps identify monthly sales patterns.

### 2. Sales by City
Provides a city-wise comparison of sales performance.

### 3. Sales by Category
Shows sales distribution across different product categories.

### 4. Profit by Category
Helps compare profit generated by different product categories.

### 5. Top 10 Products by Sales
Highlights the top-performing products based on sales.

### 6. Interactive Filters
The dashboard includes interactive filters for:

- City
- Category

These filters allow users to explore the dashboard based on selected locations and categories.
